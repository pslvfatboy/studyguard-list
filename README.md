# studyguard-list

Blocklist for the StudyGuard parental-control app. Edit `blocklist.txt` here (on GitHub.com
or the GitHub mobile app) to add/remove blocked apps — one Android package name per line,
`#` for comments. The phone re-downloads this file roughly every 60 seconds.

Raw URL to paste into StudyGuard's setup screen:

```
https://raw.githubusercontent.com/pslvfatboy/studyguard-list/main/blocklist.txt
```
